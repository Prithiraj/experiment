# S05.1 evidence — Loading policy

The production binder now assigns source URLs by explicit loading class:

- `critical`: eager with high fetch priority;
- `visible`: eager for above-the-fold supporting actors;
- `preload`: eager next-state asset and sequence anchor;
- `sequence`: loaded one group at a time after the prior state finishes;
- `deferred`: observed and assigned only within one viewport of use, with native lazy loading and low priority.

## Browser check at page start

At scroll position zero with the full motion system ready:

- the hero bud was loaded eagerly at high priority;
- the current next bloom state, leaf, and three unique visible petals were loaded;
- every image in the zero-field, orbit, axis, vortex, return, and shop remained without a `src` and had low-priority lazy metadata;
- repeated actors retained shared production URLs rather than creating new file variants.

The binder returns a cleanup that disconnects its observer and stops further sequence work on normal page teardown. Browsers without `IntersectionObserver` receive native lazy sources as a compatibility fallback.

**Verdict:** `S05.1` is **VERIFIED**.
