# S06.2 evidence — Browser and breakpoint matrix

The production build was exercised in the in-app browser at all required viewport and motion combinations.

## Matrix

| Viewport | Full motion | Reduced motion | Forced fallback | Responsive cinematic source |
| --- | --- | --- | --- | --- |
| 1440 × 900 | `ready`, 6 pin spacers | `static`, 0 pin spacers | `fallback`, 0 pin spacers | 1536 px |
| 1024 × 768 | `ready`, 6 pin spacers | `static`, 0 pin spacers | `fallback`, 0 pin spacers | 1536 px |
| 390 × 844 | `ready`, 4 pin spacers | `static`, 0 pin spacers | `fallback`, 0 pin spacers | 768 px |

Every cell produced the same acceptance results:

- all seven motion chapters and all 11 main headings were reached;
- zero broken loaded images;
- zero horizontal page overflow;
- zero unnamed links or buttons;
- all 17 unique production images were observed by the page asset inventory;
- “Add Wild Signal to bag” changed the bag label to one item, and the labelled bag button opened the dialog;
- no Zero-G Bloom warning or error was logged.

Full-motion desktop and tablet resolved all 44 production-image instances. Full-motion mobile intentionally leaves the last two field petals unresolved because the mobile actor budget hides those nodes. Reduced and fallback modes intentionally leave the four hidden intermediate chapter-state instances unresolved while loading the visible final cinematic composition. No visible image was unresolved.

The browser developer feed emits a generic `Object` entry on navigation. A temporary pre-module diagnostic capture checked `error`, `unhandledrejection`, and `console.error` from the first instruction onward and recorded zero application events; the diagnostic code was removed before the final build.

## Visual review and corrections

- The 390 px hero eyebrow was constrained to a readable two-line measure so it no longer crosses the dark backdrop at low contrast.
- The standalone full-bloom state now clears before the cinematic bloom begins, removing the doubled-flower silhouette found during tablet review.
- Hero, bud, reflection, final bloom, field, collection, horizontal phrase, vortex, reduced-motion story, fallback shop, and mobile product crops were visually reviewed.
- The collection anchor lands below the fixed header (`section top: 96 px`; heading top: 238 px at 390 px).
