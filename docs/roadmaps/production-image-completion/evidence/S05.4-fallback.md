# S05.4 evidence — Reduced-motion and static fallback parity

Both non-animated paths now select a complete, stable final composition without mounting scroll scenes.

## Implementation

- Native `prefers-reduced-motion: reduce` remains the default accessibility signal.
- Deterministic `?motion=reduced` and `?motion=fallback` profiles make both paths independently testable.
- The release hero resolves to the full-bloom cutout when animation is skipped.
- The bloom chapter resolves to the full-bloom cinematic plate; its intermediate state stack, bud plate, reflection transition, and ripple overlay cannot remain accidentally visible.
- The chapter anchor starts at the viewport edge, preserving its full-height static composition under the fixed navigation.
- Asset binding gives the reduced/static final hero image immediate loading priority while retaining intersection-based loading for later visible sections.
