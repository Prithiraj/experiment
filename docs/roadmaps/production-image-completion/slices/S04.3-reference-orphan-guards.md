# S04.3 — Reference-import and orphan guards

**Objective:** Prevent runtime imports from the reference tree and detect unmanifested production files.

## Acceptance

- Fails when application source imports `assets/reference/`.
- Fails when a runtime asset key references a file absent from the manifest.
- Reports unmanifested production files, allowing only documented metadata files.
- Confirms all `data-production-image` keys resolve to runtime asset entries.
