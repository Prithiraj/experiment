# S06.2 — Browser and breakpoint evidence

**Objective:** Verify the release candidate as a user sees it.

## Required matrix

- 1440 × 900 desktop, 1024 × 768 tablet, and 390 × 844 mobile.
- Full motion, reduced motion, and forced static fallback.
- Console/network health, image crops, hero handoff, all chapters, and cart interaction.

## Acceptance

No broken images, console errors, inaccessible controls, clipped essential content, or reference assets appear. Screenshots and observations are indexed in the evidence record.
