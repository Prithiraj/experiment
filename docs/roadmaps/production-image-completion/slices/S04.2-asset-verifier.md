# S04.2 — Asset verifier

**Objective:** Add a cross-platform repository check for manifest and file correctness.

## Acceptance

- Fails on missing or duplicate IDs/paths.
- Verifies dimensions, recorded byte sizes, hashes, and alpha expectations.
- Enforces class budgets unless an exception is documented.
- Runs through `npm run verify:assets` and is included in the normal verification path.
