# S04.1 — Manifest schema and provenance

**Objective:** Extend `assets/production/manifest.json` into the source of truth for approved assets.

## Required fields

Stable ID, role, master path, derivative paths, source type and ID, source hash when direct-derived, width, height, alpha expectation, derivative bytes, intended scenes, lifecycle status, and optional budget exception.

## Acceptance

- Every production master and derivative belongs to exactly one entry.
- Paths are repository-relative and valid.
- Existing 11 assets are migrated without changing their runtime semantics.
