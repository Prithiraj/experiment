# S03.4 — Distinct depth leaves and petals

**Objective:** Decide whether additional leaf angles or petal families materially improve 2.5D depth.

## Acceptance

- Compare candidates with the existing foreground leaf and three loose petals.
- Add only front, side, or distant silhouettes that remain visibly distinct in scene.
- Record `DEFERRED` when existing assets plus transforms supply sufficient variation.
- Any approved file passes the same alpha, provenance, naming, and payload gates as other components.
