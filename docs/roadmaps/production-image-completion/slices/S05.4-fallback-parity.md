# S05.4 — Reduced-motion and static fallback parity

**Objective:** Preserve complete content and a coherent final visual state when motion is reduced or initialization fails.

## Acceptance

- Reduced-motion mode avoids pinned, continuous, and large-axis motion.
- Static fallback exposes all sections and shopping controls.
- Deferred images still resolve when content is shown without scroll orchestration.
- No asset remains permanently transparent due to skipped animation setup.
