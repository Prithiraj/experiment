# S05.1 — Loading policy

**Objective:** Prioritize the opening hero and defer imagery that is not immediately visible.

## Acceptance

- Opening bud uses eager/high-priority loading.
- Only the next required bloom state is preloaded.
- Below-fold images use native lazy loading or a bounded intersection strategy.
- Repeated actors reuse the same cached URL.
- The evidence records the initial image request set and payload.
