# S01.1 — Source disposition

**Objective:** Classify every archived file as direct-convert, reference-board, or reference-only.

## Acceptance

- The ledger contains 21 `source` rows, one for every ID `00`–`20`.
- `01` and `02` are the only direct-convert sources.
- `03`–`17` are reference boards requiring candidate-level decisions.
- `00` and `18`–`20` are reference-only.
