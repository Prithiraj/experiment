# S01.2 — Canonical candidate inventory

**Objective:** Consolidate repeated contact-sheet concepts into the smallest useful production set.

**Invariant:** A repeated appearance is provenance, not permission to create a duplicate asset.

## Acceptance

- Each distinct lotus, water, depth, and atmosphere concept has one candidate row.
- Existing production coverage is identified so it is not regenerated unnecessarily.
- Candidate rows list all relevant archive board IDs in `source_ids`.
- Rejected/deferred concepts carry a reason.
