# S02 — Cinematic conversion

**Objective:** Promote standalone bud and bloom originals into responsive, traceable production scenes.

**Risk:** Medium. Mismatched horizon, exposure, crop, or payload would make the state handoff visibly jump.

## Children

- [`S02.1`](./S02.1-bud-scene-derivatives.md) builds the bud scene set.
- [`S02.2`](./S02.2-bloom-scene-derivatives.md) builds the bloom scene set.
- [`S02.3`](./S02.3-transition-continuity.md) verifies the pair as a transition.

## Parent acceptance

- Both production masters preserve original pixels and source hashes.
- Each scene has full and 768 px WebP derivatives within budget.
- Pairwise continuity and responsive crops are approved.
