# S03.2b — Inner structure

**Objective:** Create the minimum macro-safe inner-flower component set.

**Candidate targets:** `lotus-center-stamens`, `lotus-seed-pod`, `lotus-pollen-overlay`.

## Acceptance

- Each retained target has an approved transition use; unused concepts are explicitly deferred.
- Anatomy, scale, color, and illumination remain consistent with the full bloom.
- Fine pollen or stamen edges survive optimization at intended display size.
- Separate files are used only when independent motion is required.
