# S03.3b — Ripple and atmosphere overlays

**Objective:** Add the smallest reusable overlay set needed for ripple, sparkle, droplet, bokeh, or mist depth.

## Acceptance

- Start with one ripple overlay; add atmosphere variants only when a named scene requires them.
- Overlay edges and background treatment are transparent or demonstrably blend-safe.
- Each optimized overlay is at or below 150 KB where feasible.
- No overlay duplicates an effect already produced more efficiently in CSS.
