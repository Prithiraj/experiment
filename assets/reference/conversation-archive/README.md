# Zero-G Bloom — Conversation Image Archive

This folder contains 128px WebP reference thumbnails for all 21 successfully generated images from the design conversation. They are references only and are not imported by the storefront.

`00_florist-homepage-concept.webp` is the mistaken broad asset-board output. Keep it available for art-direction history, but do not treat it as a production image.

The original, non-compressed PNG masters are preserved locally at `../conversation-archive-originals/zero_g_bloom_generated_assets/` and intentionally excluded from the web bundle. Cancelled or incomplete generations are excluded. See `asset_inventory.csv` for source names and SHA-256 hashes.
